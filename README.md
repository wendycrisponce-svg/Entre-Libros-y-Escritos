# Entre Libros y Escritos

Proyecto de club de lectura y escritura.

Objetivo:
Crear una comunidad donde los participantes puedan leer una obra mensual, compartir experiencias, escribir ensayos y desarrollar actividades de escritura creativa utilizando Discord y futuras herramientas web.

Estado actual:
Fase de análisis, diseño y organización del proyecto.

Tecnologías previstas:

* Discord
* GitHub
* HTML
* CSS
* JavaScript
* SQLite
